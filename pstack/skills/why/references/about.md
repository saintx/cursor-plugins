# About why

## Overview

Why investigates the motivation and intent behind code. It asks what forces led to a shape: a design choice, a regression, a postmortem, or a data-backed threshold. It returns a cited read that keeps what the evidence supports separate from what it only suggests.

## When to use

Use why for why code works this way, why a choice was made, design rationale, regressions, postmortems, or where a number came from. Use the how skill when the question is what the code does or how it behaves at runtime.
