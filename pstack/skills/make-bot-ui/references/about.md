# How to make a bot UI

## Overview

Build a custom UI (page, dashboard, buttons) that wakes a Grok Bot over a webhook. That includes the case where the user must provide a webhook sender key, and the case of exposing that UI on Tailscale.

## When to use

Use when building a custom UI (page, dashboard, buttons) that should wake a Grok Bot over a webhook, when the user must provide a webhook sender key, or when exposing that UI on Tailscale.
