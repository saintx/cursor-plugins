# About poteto mode

## Overview

Poteto mode is poteto's agent style for concise, detailed responses, deliberate subagents, unslopped prose, simple code, and verified work. Its procedure holds the triggers, the principle catalog, the autonomy rules, subagent spawning, the reply, comments, and the playbook match.

## When to use

Use it for poteto, /poteto-mode, or a request to work in this style. Use poteto help when the user wants to find their way around pstack, or to be handed a prompt, rather than to have the work done.
