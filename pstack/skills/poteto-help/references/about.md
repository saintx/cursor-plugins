# About poteto help

## Overview

Poteto help answers questions about pstack setup, /poteto-mode, and which skill, playbook, or principle fits a task. The answer leads with the point, gives at most one prompt the user can send, and points at the file the answer came from.

## When to use

Use it when the user types /poteto-help or asks how pstack works. A request to do the work, such as fixing a bug, belongs to poteto mode.
